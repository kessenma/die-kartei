The Grammar tab is one path through the cases: Nominativ, Akkusativ, Dativ, Genitiv, then all four
together.

<Screens>
  <Screen src="grammatik" alt="The Grammatik tab: Up next, then the four cases" caption="Weiter shows the next unit; the coach flags what needs practice." />
</Screens>

Every unit runs the same loop: **Regel** (the rule), a **Geschichte** (read a story, mark every word
in the case, fill in the endings), then a **Schnellrunde** (quick round).
