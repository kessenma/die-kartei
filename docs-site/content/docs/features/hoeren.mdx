- **Zahlen-Diktat.** A price, time, date or phone number, heard once. Type the digits.
- **Diktat.** Hear a sentence, write it, and see which endings you missed.
- **Worum geht's?** Guess the words first, listen to a story, then say what it was about.

These follow the listening tests of the US Defense Language Institute. Only Worum geht's? uses the
AI model, to write the key points your summary is compared with.
