# Stammtisch — conversation under pressure

Roadmap item 8 (`FSI-10`: conversation is the hardest skill; learners must practise "following
rapid and unpredictable turns in topic", "producing unplanned speech", "coping with the speed of
the turn-taking" and "coping with background noise"). A free conversation with the Stammtisch
toggle on (Conversation setup ▸ Stammtisch).

| Piece | Where |
|---|---|
| Options (`topicEvery`, `replySeconds`, `backgroundNoise`), topics, listener phrases | `Models/Stammtisch.swift` |
| Persona, topic note, silent-turn note | `Services/ConversationPrompts.swift` |
| Topic injection, `tutorMovesOn`, noise during playback | `Services/ConversationEngine.swift` |
| Background noise | `Services/StammtischNoise.swift` |
| Listener replies and the countdown | `Features/Conversation/StammtischBar.swift` |
| Setup | `ConversationSetupView.stammtischSection` |

- **The app changes the topic, never the tutor.** Every third learner turn `runReply` appends a
  one-line note to the system prompt ("Wechsle jetzt das Thema … : <topic>"), from a list of 16
  everyday topics rotated from a per-chat offset (`StammtischTopics.seed`). Same hook as the
  interview's progress note; `ChatTurnNormalizer` stays the only prompt path.
- **Persona**: short turns, everyday spoken German, one quick question at a time.
- **Reply timer** (optional, 10–60 s): counts from the moment the tutor stops speaking, stops while
  the learner records or types. At zero the tutor moves on: `runReply(silentLearner:)` sends a hidden
  user line `(…)` (never stored) and a note to react lightly and ask something easier. Two assistant
  turns in a row are fine: the normalizer merges them for the next request.
- **Background noise** (optional, off by default): soft brown noise with a slow swell, generated by
  an `AVAudioSourceNode` (no recording bundled), played only while the tutor speaks so it never
  reaches the microphone. The render block is built outside the main actor.
- **Listener phrases**: one tap sends „Ach so!“, „Genau.“, „Echt?“ … as the learner's turn; the
  setup can add all ten to the Phrasen deck as phrase cards.
- **Saved with the chat**: `ChatConversation.stammtischData` (synced, `ChatConversationCodec`
  "stammtisch"), read back by `makeConfig`, so a resumed chat is still a Stammtisch. The other
  config sites (paper, weekly recap) never set it.
- Later: two tutor voices in one chat (stories already have dialogue voices).
